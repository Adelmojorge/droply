Política de Privacidade

Última atualização: novembro de 2026 · Drop Code Studio

Esta política explica que dados o droply (operado pela Drop Code Studio) trata e porquê.

1. Dados da tua conta

Quando entras com o Google, recebemos o teu nome, e-mail e foto de perfil. Usamo-los só para te identificar, verificar se tens acesso e contar a tua utilização mensal (número de pesquisas, análises e sites). Não recebemos a tua palavra-passe.

2. Dados guardados no teu navegador

Os leads, a pipeline, as notas, os sites criados e o teu tom de voz ficam guardados apenas no armazenamento local do teu navegador. Não os guardamos nos nossos servidores. Podes exportá-los ou apagá-los em Definições.

3. Dados enviados para processamento

Quando fazes uma pesquisa, o pedido é enviado ao Google Maps Platform. Quando analisas um lead ou crias um site, os dados públicos dessa empresa e o teu perfil de vendedor são enviados ao fornecedor de IA configurado (OpenAI ou Anthropic) para gerar a resposta. Estes fornecedores tratam os dados segundo as suas próprias políticas.

4. Dados das empresas pesquisadas

O droply mostra informação pública de empresas (nome, morada, telefone, site, avaliações e contactos publicados no próprio site). Quem usa o droply é responsável por contactar essas empresas de forma legal, respeitando a legislação aplicável (por exemplo, o RGPD na União Europeia) e os pedidos para não ser contactado.

5. GitHub

Se ligares o GitHub, o token de acesso fica só no teu navegador e é usado para criar repositórios e enviar os sites que escolheres publicar.

6. Os teus direitos

Podes pedir informação ou a eliminação dos dados da tua conta (e-mail e contadores de utilização) através do suporte. Os dados no teu navegador apagas tu, em Definições.

7. Contacto

Drop Code Studio · através do suporte indicado na aplicação.
